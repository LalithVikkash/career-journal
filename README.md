# Career Journal

A full-stack web application for recording learning activities and tracking skill-development progress.

## Features

- Add learning entries
- View learning entries
- Edit existing entries
- Delete entries
- Search entries by title or skill
- Track completed and in-progress learning activities
- Dashboard statistics

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Database

SQLite is used to store learning entries with CRUD operations.
